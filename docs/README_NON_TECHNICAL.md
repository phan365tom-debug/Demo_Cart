# Demo Cart - Simple Guide (Non-Technical)

This guide explains Demo Cart in simple words.

## What Is Demo Cart?

Demo Cart is a sample online shopping app.

It shows how a real shopping website can work, including:

1. User login
2. Product browsing
3. Add to cart
4. Checkout and payment
5. Order tracking
6. Refund request and admin approval

## Who Can Use It?

There are 2 roles:

1. User: buys products, tracks orders, requests refunds
2. Admin: reviews refund requests and decides approve or reject

## Demo Login Details

User account:

1. Username: user1
2. Password: User@123

Admin account:

1. Username: admin
2. Password: Admin@123

## How To Use (User)

1. Login as user.
2. Open Catalog and add products.
3. Go to Cart and click Checkout.
4. Go to Payment.
5. Enter name, email, shipping address, and card last 4 digits.
6. Click Pay Now.
7. Open Orders tab.
8. Click Track Product to see order progress.
9. If needed, enter reason and click Request Refund.

## How To Use (Admin)

1. Login as admin.
2. Open Admin Refunds tab.
3. Check refund requests from users.
4. Click Approve Refund or Reject Refund.
5. If rejecting, add a reason.

## Main Screens Explained

1. Catalog: list of products
2. Cart: selected items
3. Payment: customer, shipping, and payment details
4. Orders: order status, tracking, refund request
5. Admin Refunds: refund decision page for admin

## Tracking Meaning

Order tracking can show steps like:

1. Order placed
2. Payment confirmed
3. Packed
4. Shipped
5. Out for delivery
6. Delivered

## Refund Meaning

Refund status can be:

1. Pending: waiting for admin review
2. Approved: refund accepted
3. Rejected: refund not accepted, with reason

## Common Problems (Simple)

1. Page not opening:
Check internet or ask the project owner if server is running.

2. Login not working:
Make sure username and password are typed exactly.

3. Refund button fails:
Only paid orders can request refund.

4. Cloudflare page shows NoAuth:
Access permission is missing. Ask admin to allow your email in Cloudflare Access policy.
